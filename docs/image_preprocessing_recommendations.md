# 铝液滴燃烧图像预处理建议

本文档用于整理铝液滴燃烧图像在 YOLO-seg 识别前可以采用的预处理方法，以及这些方法对飞溅液滴识别、mask 质量、轨迹和速度计算的影响。

## 1. 基本原则

预处理可以减少光晕、过曝、背景噪声、亮度变化等因素对识别结果的干扰，但必须遵守一个原则：

```text
训练时怎么处理图片，推理时也要用同样的处理方式。
```

如果训练集使用原始彩色图片，而推理时改成灰度图、增强图或裁剪图，模型输入分布会发生变化，可能导致识别效果变差。因此，任何预处理方案都应同时用于：

```text
训练集图片
验证集图片
测试/推理图片
```

## 2. 推荐优先级

建议按以下顺序尝试：

```text
ROI 裁剪
→ 亮度归一化
→ 灰度三通道化
→ CLAHE 局部对比度增强
→ 轻微去噪
→ mask 后处理
```

不要一开始就使用很强的阈值化或过度增强，否则可能会损失弱小液滴，或让模型学习到预处理伪影。

## 3. ROI 裁剪

### 作用

ROI 裁剪是最推荐优先尝试的预处理方式。

铝液滴燃烧图像中，真正关心的区域通常是主体液滴上方的飞溅区域。整张图中大量黑色背景和无关区域会降低小液滴在图像中的占比。

ROI 裁剪可以：

```text
增大小液滴在输入图像中的相对尺寸
减少背景干扰
降低模型学习难度
提升推理速度
减少主体液滴以外区域的误检
```

### 注意事项

裁剪区域必须保持一致，不能训练时裁剪一套区域、推理时裁剪另一套区域。

如果主体液滴位置在不同实验中变化较大，可以考虑：

```text
固定裁剪区域
或先检测主体液滴，再根据主体液滴位置动态裁剪
```

## 4. 灰度三通道化

### 作用

灰度图可以减少颜色变化对模型的影响，让模型更关注亮度、形状和边界。

适用于：

```text
火焰颜色变化较大
相机颜色响应不稳定
飞溅液滴主要依赖亮度而非颜色区分
```

### 推荐做法

不要直接使用单通道灰度图。YOLO 通常期望 3 通道输入，因此建议：

```text
原图
→ 转灰度
→ 复制为 3 通道灰度图
→ 输入 YOLO-seg
```

### 风险

如果颜色本身有助于区分液滴、火焰、氧化帽和背景，灰度化可能损失有效信息。因此灰度方案需要和原图方案做对比实验。

## 5. CLAHE 局部对比度增强

CLAHE，全称 Contrast Limited Adaptive Histogram Equalization，即限制对比度的自适应直方图均衡。

### 作用

CLAHE 可以增强局部弱对比区域，使暗淡小液滴更容易被模型识别。

适用于：

```text
暗弱飞溅液滴漏检
图像整体偏暗
液滴边界不明显
背景亮度不均匀
```

### 风险

CLAHE 可能同时增强背景噪声和热噪点，导致误检增加。因此不建议单独依赖 CLAHE，最好配合：

```text
面积阈值过滤
圆度过滤
置信度过滤
人工检查 overlay 结果
```

## 6. Gamma 校正

Gamma 校正可以调整图像亮度分布。

### 作用

对于过暗或过亮的图像，可以通过 Gamma 调整改善液滴可见性。

常见用途：

```text
压低过曝光晕
增强暗弱液滴
减少主体液滴强光对周围区域的影响
```

### 注意事项

Gamma 参数不应随意变化。建议在一组固定参数下处理全部训练和推理数据，避免模型输入分布不一致。

## 7. 轻微去噪

可以使用轻微的高斯滤波、中值滤波或双边滤波减少背景噪声。

### 作用

```text
减少黑色背景中的随机亮点
降低小噪点误检
让 mask 边界更平滑
```

### 风险

滤波过强会模糊真实小液滴，导致漏检。因此去噪强度要轻。

## 8. 背景扣除

如果实验中背景稳定，可以使用背景扣除降低固定光斑、暗纹、相机噪声和背景反射影响。

可选方法：

```text
用燃烧前图像作为背景
用多帧中位数图像作为背景
当前帧减背景图
```

### 风险

如果主体液滴和火焰形态变化大，背景扣除可能引入伪影。背景扣除更适合做辅助增强，不建议一开始作为主方案。

## 9. 不建议优先使用的处理

以下方法不建议一开始使用：

```text
强阈值二值化
过强锐化
大范围腐蚀/膨胀
只保留最亮区域
过度去光晕
```

原因是这些方法可能会：

```text
删除暗弱真实液滴
改变液滴真实边界
破坏面积和圆度计算
制造非真实边缘
导致模型学习预处理伪影
```

## 10. mask 后处理

即使 YOLO-seg 已经输出 mask，仍可以在后处理阶段过滤明显不合理的结果。

建议增加的规则包括：

```text
最小面积阈值
最大面积阈值
最小等效直径
最大等效直径
圆度阈值
与主体液滴区域的空间关系过滤
短断帧轨迹重连
缺失帧插值
```

例如：

```text
面积过小：可能是背景噪点
面积过大：可能是主体液滴边缘或光晕
圆度过低：可能是拖影、烟迹或分割错误
贴近主体液滴内部：可能不是独立飞溅液滴
```

## 11. 推荐实验路线

建议设计三个版本做对比：

### 版本 1：原图方案

```text
原始图像
→ YOLO-seg
→ ByteTrack
→ 参数计算
```

作用：作为 baseline。

### 版本 2：ROI 裁剪方案

```text
原始图像
→ 裁剪主体液滴上方 ROI
→ YOLO-seg
→ ByteTrack
→ 参数计算
```

作用：优先解决小液滴占比太低和背景干扰问题。

### 版本 3：灰度 + CLAHE + ROI 方案

```text
原始图像
→ 裁剪 ROI
→ 灰度化
→ CLAHE 增强
→ 转为 3 通道
→ YOLO-seg
→ ByteTrack
→ 参数计算
```

作用：重点解决暗弱液滴、局部对比度低和光照不均问题。

## 12. 评价指标

比较不同预处理方案时，不应只看 YOLO 的 mAP，还要看实际工程指标：

```text
飞溅液滴漏检是否减少
主体液滴边缘误检是否减少
小液滴是否能稳定识别
mask 是否贴合真实液滴边界
面积、圆度和等效直径是否稳定
track_id 是否连续
速度曲线是否出现异常跳变
插值点比例是否过高
```

## 13. 当前项目建议

针对当前铝液滴燃烧图像，建议优先尝试：

```text
ROI 裁剪
imgsz = 1024 或 1280
conf = 0.10-0.15
ByteTrack + 断帧重连
必要时加入灰度三通道 + CLAHE
```

在重新训练模型前，应先整理模型失败样本，重点补充：

```text
小飞溅液滴
暗弱飞溅液滴
模糊飞溅液滴
靠近主体液滴边缘的液滴
有拖影的飞溅液滴
背景亮点干扰样本
```

最终目标不是单纯让图片看起来更清楚，而是让模型稳定输出可用于后续物理计算的 mask、中心坐标、面积、圆度、轨迹和速度。
